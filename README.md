# Bizmarket

Business marketplace platform for buying/selling businesses across India.

## Features
- Browse verified business listings by category/location
- Seller dashboard for listing businesses
- Buyer dashboard with recently viewed
- Premium listings & business valuation
- Responsive design with dark/light theme
- React 19 + Vite + TailwindCSS v4

## Quick Start
```bash
npm install
npm run dev
```

Open http://localhost:5173

## Tech Stack
- React 19 + React Router
- TailwindCSS v4 (@tailwindcss/vite)
- Framer Motion (animations)
- Vite 7 (HMR optimized)
